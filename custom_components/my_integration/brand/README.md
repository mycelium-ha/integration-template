# Brand Assets

Place your integration's brand images directly in this folder (no PR to `home-assistant/brands` required):

- `icon.png` (256x256 px)
- `icon@2x.png` (512x512 px)
- `logo.png` (height 128–256 px, width up to 512 px)
- `logo@2x.png` (2x resolution of `logo.png`)

Home Assistant and the Home Assistant Marketplace automatically pick up these assets from your repository releases.
